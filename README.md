# State of the Canadian tech job market: late 2026

An Open Nshipyard data story. Canada's tech job market in late 2026, measured with open Canadian data: which roles are hiring, which are shrinking, and where the work is moving.

Live at https://techjobs.canada.nshipyard.com

## What is in this repo

- `index.html`: the report front page with all 7 takeaways and charts.
- `article.html`: the full long-form report.
- `charts/`: the 7 charts, Lenny-style, white background.
- `og/`: share images (1200x630) for each chart.
- `chart-1.html` to `chart-7.html`: per-chart share pages.
- `The-State-of-the-tech-job-market-in-Canada-Late-2026-final-v6.pdf`: the report as a PDF.
- `showcase.html`: showcase page.

## Sources

Statistics Canada table 14-10-0444-01 (Job Vacancy and Wage Survey), Indeed Hiring Lab Canada, Job Bank, Labour Force Survey, CBRE Scoring Tech Talent 2026, Robert Half Canada via TalentNeuron. Full method and sources are on the site and in the PDF.
